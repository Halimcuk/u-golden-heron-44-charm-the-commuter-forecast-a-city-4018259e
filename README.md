A one-line weather forecast for the invented city of Drizzlewick, where light rain falls upwards and the morning bus arrives dry, on time, and faintly smug — written to charm a bored commuter on the way to work.

> In Drizzlewick, light rain falls upwards this morning, so umbrellas stay folded and the 8:15 bus arrives dry, on time, and faintly smug.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output node main.ts
```

The entry line is 136 characters. The output is deterministic: the same line is written on every run.
